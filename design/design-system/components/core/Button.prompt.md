Brand CTA link/button; use for every call to action, always square-cornered with an arrow glyph in the label.

```jsx
<Button variant="primary" href="#">Book a call →</Button>
<Button variant="secondary">See full faculty →</Button>
```

Variants: primary (orange, hovers plum) · secondary (plum outline, fills on hover) · chartreuse (for dark sections) · link (underlined). Labels are verbs; arrows are text glyphs (→).
