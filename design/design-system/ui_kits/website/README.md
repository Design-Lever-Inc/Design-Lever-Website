# Website UI kit

Interactive click-through recreation of the Design Lever marketing website, built from the design-system foundations (`../../styles.css`) and real brand assets (`../../assets/`).

`index.html` is a faithful Home-page recreation: sticky nav with hover dropdowns, blush-pink hero with the corner motif (uniform `4 8` dashes), trust-logo strip, an auto-advancing testimonial, a filter-pill demo, the diagnostic CTA band, and the canonical plum footer. It demonstrates the established conventions rather than re-implementing the JSX primitives.

Tagged as a Design System card (group "Website") and as a Starting Point so new pages can be seeded from it.

Live source of truth: the `Design Lever *.dc.html` pages in the project root.
